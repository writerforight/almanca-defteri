# Almanca Defteri

Almanca çalışma notlarım — aynı konulara dönüp dönüp çalışmamak için.

- `konular.md` — çalışılan her şeyin ana listesi (konu — ilk tarih — tekrar sayısı — not)
- `oturumlar/YYYY-MM-DD.md` — her çalışma gününün notları
- `llm-istemi.md` — oturum sonunda LLM'den liste almak için hazır istem
- `index.html` — arayüz; `python3 olustur.py` ile md dosyalarından üretilir (şablon: `sablon.html`)
